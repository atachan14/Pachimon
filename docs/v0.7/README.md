# v0.7 City

Cityのラインナップ生成、事前閲覧、購入、在庫状態の保持を実装する。

## 完了条件

1. Map生成時に各Cityの商品と価格が確定する
2. Cityへ移動する前からRightPaneでラインナップを閲覧できる
3. City滞在中にGoldを支払い、空いているItem Slotへ商品を追加できる
4. 購入済み商品はRun中に復活しない
5. 何も購入せずにCityを完了できる
