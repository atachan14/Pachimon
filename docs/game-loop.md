# Game Loop

`firstDocument.md` はアーカイブとして残し、このファイルを現行のゲーム進行仕様とする。

## 目的
- ラン開始から終了までの進行を定義する
- battle / reward / map / save / ghost の接続を整理する
- UI仕様ではなく、ゲーム進行上の状態遷移を整理する

## コアループ
1. タイトル表示
2. `new game` または `continue`
3. 初期編成（row:0）
4. map上で次ノード選択
5. ノード内容を解決
6. battle終了後にreward解決
7. 次ノードへ進行
8. row:36のパチモンリーグでbadge条件を満たしていたら、row:37以降へ進行
9. row:40クリアで殿堂入り演出
10. GhostAreaへ進行
11. Ghostエリア完走、または敗北でrun終了

## タイトル
### 表示項目
- さいしょから
- つづきから
- 設定
- 言語切替

### 遷移
- `さいしょから` -> 初期編成
- `つづきから` -> セーブデータ確認後に前回位置へ復帰
- `設定` -> 設定画面

## 初期編成
### 目的
- run開始時の味方3体を決定する

### 現在方針
- 共通プールから候補を提示する
- プレイヤーは3体を選択する
- 選択後、戦闘用の初期隊列を確定する
    > 初期隊列は選択順をそのまま使う

### 要決定
- 候補提示数
    > 3*3の9対
- 重複出現の可否
    > 敵の出現含めて、同一run内で同種は重複しない
- 選択順と初期配置順を一致させるか
    > 一致させる
- rerollの有無
    > なし

## Map
### 役割
- run進行のメイン画面
- 次に進むノードを選ぶ

### ノード種別
- 通常
- ジム
- 四天王
- パチモンセンター
- シティ/タウン(ショップ)
- ghost

### ノード事前表示
- 種別
- パチモン情報
- 報酬gold
- 報酬mod
- badge情報

### 遷移
- ノード選択 -> ノード詳細確認
- `進む` -> 各ノード処理へ

## Battle
### 開始時
- 敵編成生成
- 味方編成読み込み
- battle用状態を初期化
- 先攻順は各個体の初期TurnCDで決定

### 終了条件
- 敵全滅で勝利
- 味方全滅で敗北

### 終了後
- 勝利時: rewardへ
- 敗北時: run終了処理へ

## Reward
### 現在方針
- 戦闘勝利後に報酬を提示する
- プレイヤーは基本的に全ての報酬を受け取る
- 付与先のパチモンを1体選ぶ

### 報酬候補
- パチモンの能力
    - skill
    - mod
    - passive
- gold
- （ジム戦）badge
- （四天王戦/ghost戦）上記報酬がなく、代わりに全味方が最大HPの20%を回復

### 要決定
- 1戦あたりの提示数
    > 全て
- 通常戦 / ジム戦 / 四天王戦で報酬テーブルを分けるか
- スキップ不可

## Gym
### 役割
- badge獲得ノード
- 中ボス的な節目

### 勝利時
- badge獲得
- 特別報酬の有無を後で定義
    > badgeが特別報酬

### 要決定
- badgeの具体効果
    - 全味方のfire*50%
    - 全味方のwater*50%
    - ...
    (それぞれジムリーダーの得意属性に一致)
- ジム固有ルールの有無
    > 無し

## 四天王
### 役割
- run終盤の高難度エリア

### 現在方針
- 高倍率補正あり
- 報酬なし
- 最終試験ポジション

### 要決定
- 連戦形式か
    - yes
- 回復タイミング
    - 無し
- クリア条件
    - 全撃破

## パチモンセンター
### 仮役割
- 味方の状態回復

### 要決定
- HP全回復か
    - 全味方のHPを最大HPの50%回復
- MN全回復か
    - MNはバトルごとに全回復
- 状態異常解除の有無
    - 状態異常は持ち越さない

## ショップ
### 仮役割
- goldを消費して強化要素を獲得する

### 要決定
- 商品カテゴリ
    - 傷薬
        - 小
        - 中
        - 大
    - 戦闘アイテム
        - buff
            - 戦闘中、選択したパチモンのFire+50%
            - ...
        - debuff
        - ダメージ付与
            - 300のFireダメージを与える
            - 100のfireダメージを敵全体に与える
            - ...
        - シールド付与
        - 特殊

    - 技マシーン
    - mod

- reroll
    > goldを消費して可
- 売却の有無
    > 無し

## Ghost
### 発生
- 殿堂入り後、プレイヤー敗北時もしくはGhostArea完走時にghostを保存する

### map上の扱い
- 後続runのghostノードとして出現する

### 保存候補
- username
- date
- version
- パチモンリスト
    - stats
    - skills
    - passives
- 出現位置

出現位置のみ、後続runにより変動する（前段階で敗北したプレイヤーが前に割り込むため）

## Run終了
### 敗北時
- （殿堂入り後）ghost保存
- セーブ整理
- タイトルへ戻る

### クリア時
- ghost保存
- runデータ削除
- タイトルへ戻る

## セーブ
### ブラウザ版の現行メモ
- username
- token
- run状態

### 要決定
- 保存タイミング
- ノード進行中の中断可否
- バージョン差分の扱い
