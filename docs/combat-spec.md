# Combat Spec

`firstDocument.md` はアーカイブとして残し、このファイルを現行の戦闘仕様とする。

## 目的
- battle中の内部ルールを整理する
- データ構造と処理順を定義する
- `stats.md` の内容を実装寄りに受ける土台にする

## 戦闘の前提
- 3 vs 3 の戦闘
- 各個体が独立した `TurnCD` を持つ
- 各skillが独立した `SkillCD` を持つ
- tickベースで内部時間を進める
- `TurnReady` の個体のみ行動できる

## 用語
### tick
- battle内の内部時間単位
- 整数で管理する

### TurnCD
- 次に行動可能になるまでの待機時間

### SkillCD
- 次にそのskillを使用可能になるまでの待機時間

### TurnReady
- 個体が行動選択可能な状態

## 戦闘開始
### 初期化
- 味方3体を戦闘状態に変換
- 敵3体を戦闘状態に変換
- HP / MN / 状態異常 / 各種CDを初期化
- 初期Turn順を計算

### 要決定
- battle開始時のMN値
  > maxMN
- passive適用タイミング
  > passiveにより異なる
  > ivent駆動？
- 先制効果の解決順
  > turnReadyごとに解決する。

## 隊列
### 基本
- 味方と敵はそれぞれ前から `index 1, 2, 3`
- `index 1` が先頭

### 死亡時
- 内部的にはlistから排除し、UI上はそのindex位置を空欄とする。


## ターン進行
### 基本フロー
1. 次に `TurnReady` になるtickまで進める
2. `TurnReady` になった個体を確定する
  1. TurnMenu（たたかう/アイテム）
    - たたかう
      1. 行動可能なskillを提示する
      2. skillを選択する
      3. 対象は自動決定
      4. 効果を解決する
      5. 次の `TurnCD` と `SkillCD` を設定する
      6. Turnを終える
    - アイテム
      1. 使用可能なitemを提示する
      2. itemを選択する。
      3. 対象は自動決定
      4. 効果を解決する
      5. Turnは終わらない
      6. [戻る]でTurnMenuに戻る
3. 1,2を繰り返す
4. 勝敗判定を行う

## CD計算
### TurnCD
- `speed` によって短縮される

### SkillCD
- `skillheist` によって短縮される

### 参考式
```text
nextTurnTick = now + baseTurnCD / (1 + speed / 100)
nextSkillReadyTick = now + baseSkillCD / (1 + skillheist / 100)
```

## クリティカル

## 状態異常
### 現状
- `状態異常:n%` の枠はある
- 種類は未確定

### 要決定
- 種類一覧
共通して、効果中に同じ状態異常を受けるとnは蓄積する。
  - 火傷(n)
  自身のTurn毎にnに応じたダメージを受け、効果期間中はnに応じて与えるダメージを割合で減少させる
  Turnごとに(ダメージ計算前に)nから自身のfireに応じた値を引いて、nが0になったら終了

  - びしょ濡れ(n)
  skill使用時のTurnCDをnに応じて固定値で増加させる。
  Turnごとにnからwaterに応じた値を引いて、nが0になったら終了

  - 花粉症(n)
  skill使用時のskillCDをnに応じて固定値で増加させる。
  Turnごとにnからleafの値を引いて、nが0になったら終了
  
  - 感電(n)
  electric属性のダメージを受ける/与えるとき、
  そのダメージをnに応じて、割合で味方にも与える。
  発生ごとに（計算前に）nからelectricに応じた値を引いて、nが0になったら終了

  - 猛毒(n)
  nに応じたtickごと（nの上昇に伴い頻度も上昇）にnのダメージ
  ダメージのたびにnは割合で増加する
  nの増加率は自身のpoison値で軽減
  （仮）poison=0で4倍、poison=100で2倍、poison=200で1.5倍

  - 柔化(n)
  獲得するシールドがnに応じて減少する。
  Turn毎にearthの値に応じてnを減少させ、nが0になったら効果終了

  - 凍結(n)
  nに応じたtickの間、turnCDとSkillCDが進まない（スタン）
  凍結を受ける際、iceの値に応じてnを軽減する。

  - 混乱(n)
  与えるダメージのn%を自身にも与える。
  Turnごとにdragonの値に応じてnを減少させ、0になったら効果終了

- 重複可否
  > 可
- 持続tick
  > 上記の通り、turn単位での解決が多いが状態異常種類依存。
- 解決タイミング
  > 上記の通り、状態異常種類依存

## MN
### 現状メモ
- MNを消費するタイプのskillもある
- MNは戦闘開始時に全回復する
  > 戦闘終了後に変更
- HPは持ち越す

### 要決定
- 通常攻撃相当skillのMN要否
  > 通常攻撃という概念はなく、全て同様にskillとして扱う
  > skillによってMNを必要としたりしなかったりする
- MN回復手段
  > 戦闘中はMNregによってtickごとに回復
  > 先頭終了後に全回復
