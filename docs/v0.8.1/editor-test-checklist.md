# Editor Test Checklist

Unity Editorで確認が必要な、見た目・操作・Scene接続を一時的に管理する。
数式や特殊な戦闘条件は可能な限りEditMode Testで保証し、このリストには人の目や操作が必要な項目だけを残す。

## 使い方

- 未確認は`[ ]`、確認できたら`[x]`にする。
- 修正後の再確認が必要になった項目は`[ ]`へ戻す。
- 厳密な再現条件が不明な場合、覚えている範囲だけを「発生メモ」に残す。
- 確認済みの項目は、対象バージョン公開後にこのファイルから削除または結果へ移す。
- 新しい問題や改善案そのものは、プロジェクト共通の[`backlog.md`](../backlog.md)へ記録する。

## 確認待ち

### Reward Overlayの再表示

- [ ] 1回目のBattle報酬で5種すべて取得できる。
- [ ] 2回目以降のBattle報酬でも、5ボタンの表示と操作が正常である。
- [ ] Item報酬で、回復量400の「きずぐすり」か「MNポーション」を1個だけ取得できる。
- [ ] Item報酬取得後、選ばなかったItemを追加取得できない。
- [ ] バッグが満杯の場合はItem報酬を確定できず、残りの報酬を放棄して進める。
- [ ] Skill / Passive選択で、選択先Pachimonの画像・名前・選択可否が正しい。
- [ ] 一部の報酬を取得後に「残りを放棄して進む」を押すと、取得済み報酬を維持したままMapが開く。
- [ ] 報酬を何も取得せず放棄した場合も、BattleNodeが完了して次Nodeを選択できる。
- [ ] 報酬取得時の縮小・回転と、全取得後のOverlay収納が正常である。
- [ ] UIの重複やConsole Errorが発生しない。

目的:

- Main報酬ボタンと選択先カードの再利用後も、前回の表示状態が残らないことを確認する。

### 動的Speed変化中の発生Skill

- [ ] 雨など、戦闘中にSpeed補正が変化する状態で発生のあるSkillを使う。
- [ ] ActionGaugeが右端へ到達する前にSkillが発動しない。
- [ ] ActionGaugeが右端へ到達した後は正常にSkillが発動する。
- [ ] `The pending Skill has not reached its resolve Tick.`が発生しない。

発生メモ:

- 元の発生条件は未特定。
- 原因として、発生開始時の予測後にSpeedが変化し、予測Tickと実際の進行がずれるケースを確認した。
- 雨男と減衰中の雨を使うケースはEditMode Testで再現済み。

自動テスト:

- `NumericCalculationTests.BattleFlow_RecalculatesPendingResolveWhenDynamicSpeedFalls`

### フィールド・天候カードの再利用

- [ ] フィールド生成物を生成すると、対応するLaneへカードが表示される。
- [ ] 天候を発生させると、中央Laneへカードが表示される。
- [ ] Value、残りTick、障壁HPなどが戦闘進行に合わせて更新される。
- [ ] 効果終了後にカードが消える。
- [ ] 消えた後に別の効果を生成しても、色・テキスト・クリック先が以前の内容にならない。
- [ ] カードクリックで正しい詳細Overlayが開く。
- [ ] 1つのLaneへ多数の生成物を並べても、そのLaneだけを横スクロールでき、他の2つのLaneが横へ押し出されない。
- [ ] 炎の障壁へShield破壊Skillを当てると、障壁の現在HPを全量破壊してカードが消える。
- [ ] 炎の障壁が攻撃を全量吸収した場合、毒素・弱点・風化はPachimonではなく障壁へ付与される。
- [ ] 炎の障壁へ付与した毒素が障壁HPを減らし、弱点が次の障壁Damageで消費され、風化が障壁のResistBonusを低下させる。
- [ ] Slow・Stunは炎の障壁へ保持されず、Pachimonへ貫通もしない。
- [ ] 炎の障壁がFireまたはLeafの攻撃Damageを受けると、同陣営のファイアヴァインが反応する。

目的:

- カードの毎回破棄をやめて再利用する変更後も、表示内容とイベントが正しく更新されることを確認する。

### Cityの商品行の再利用

- [ ] MapからCityを選択し、RightPaneで商品ラインナップを確認できる。
- [ ] 各Cityに無属性技マシン1個と属性技マシン1個が表示される。
- [ ] 複数Cityを通して、同じ専用技マシンが重複して配置されていない。
- [ ] きずぐすりとMNポーションの個数はCityごとに揺らぎ、どのCityにも1個以上ある。
- [ ] 元気のかけらが全City合計40個配置され、価格と復活HPが`70%`から`130%`で揺らぐ。
- [ ] 元気のかけらは生存中のPachimonには使えず、戦闘不能のPachimonを表示値のHPで復活させる。
- [ ] 同名の回復Itemが小アコーディオンへまとまり、個別価格を展開できる。
- [ ] 回復Item名に実際の効果量が表示され、高価格ほど効果量が低くならない。
- [ ] 購入後のItem Panelと詳細Overlayにも同じ効果量が表示され、使用時の回復量へ反映される。
- [ ] City滞在中もRightPaneは移動前と同じ全ラインナップを表示し、購入操作を表示しない。
- [ ] MainPaneで商品を購入すると、RightPaneへ売り切れ状態が即時反映される。
- [ ] 商品を1個購入すると、MainPaneの購入済み表示・所持Gold・残り商品の購入可否が更新される。
- [ ] 続けて複数の商品を購入しても、行の重複や消失が起きない。
- [ ] 商品詳細を開くと、選択した商品の詳細が表示される。
- [ ] カテゴリを閉じた状態で購入しても、カテゴリの開閉状態が不意に戻らない。
- [ ] 別のCityを表示したとき、前のCityの商品や購入状態が残らない。
- [ ] 刻印屋に14種類の小カテゴリがあり、各Statの刻印が1個以上表示される。
- [ ] 刻印名に主効果量、詳細Overlayに主効果と副作用が表示される。
- [ ] 同種の刻印では、高価格な商品ほど主効果が低くならない。
- [ ] MainPaneで刻印を選び、Pachimon選択Overlayから対象1体へ直接適用できる。
- [ ] 複数の刻印を選んだ場合、Gold消費・全効果適用・売り切れ化が一括で成功する。
- [ ] 刻印は1体につき9個まで保持でき、選択分を含めて10個以上になる対象は選択不可になる。
- [ ] 各Cityの装備品に、冠 / 勾玉 / 靴を合わせて6個表示できる。
- [ ] 複数Cityを通して、24種の装備定義が各2個、合計48個配置される。
- [ ] 装備詳細に部位、主属性、追加属性、部位固有のSubStat対応率増加が表示される。
- [ ] 装備品が価格昇順で表示され、高価格ほど冠2倍化前の主属性値が低くならない。
- [ ] MainPaneの装備屋から対象Pachimonへ直接装着でき、ItemSlotへ追加されない。
- [ ] PachimonTabのPassive欄の下に、頭 / 胴 / 足の装備3枠が表示される。
- [ ] 装備購入後、対象Pachimonの装備名と効果がPachimonTabへ即時反映される。
- [ ] 装備欄の下に刻印欄が表示され、適用済み刻印の主効果と副作用を確認できる。
- [ ] 勾玉または靴の装着後、対応属性とSubStat対応率は変化せず、HSTまたはSPDの実効値だけが固定値で増加する。
- [ ] SlowなどのBattle効果でSubStatが負数になっても、対応属性値は変化しない。
- [ ] 対象部位が埋まったPachimonは選択不可理由とともにグレーアウトする。
- [ ] 薬局で選択中の商品数、合計価格、空きItemSlot数に応じて購入ボタンが更新される。
- [ ] 薬局の一括購入は、残高不足や空き不足のとき一部の商品だけ購入されない。
- [ ] 技インストラクターからSkillを直接習得でき、技マシンItemはItemSlotへ追加されない。
- [ ] Skillを6個習得済みのPachimonは、未習得Skillに限り理由とともにグレーアウトする。
- [ ] 各Cityに技忘れマシンが1個以上あり、Run全体で合計16個配置される。
- [ ] 技忘れでPachimonを選ぶと、同じOverlay内で所持Skillの3列Gridへ切り替わる。
- [ ] Skill選択後に詳細Overlayを開閉しても、選択中の技と技忘れOverlayが維持される。
- [ ] 習得済みSkillを技マシンや技インストラクターで再取得すると、Slotを増やさずアップグレードされる。

- [ ] 技忘れ確定時にGold消費と売り切れ化が同期し、キャンセル時にはどちらも変化しない。

目的:

- 購入のたびに商品行を作り直さず、同じ行を更新する変更後も表示と操作が正しいことを確認する。

### Item使用判定サービスの共有

- [ ] Itemをドラッグ中に、有効・無効な対象の枠表示が正しく切り替わる。
- [ ] Player、Map上のEnemy、Battle中のEnemyへ、使用可能なItemを正常に使える。
- [ ] 使用不可対象ではItemが消費されず、以前と同じ失敗理由になる。

目的:

- Run中に使用判定サービスを共有しても、対象判定とItem効果が以前と変わらないことを確認する。

## 不具合発生時に残すもの

全部を覚えておく必要はない。分かる範囲で以下を残す。

- Run Seed
- Row / Node種別
- PlayerとEnemyのPachimon名
- 使用したSkill
- 目立っていた状態・フィールド・天候
- 直前に押したボタン
- Consoleの先頭の例外とStack Trace
- 可能なら発生直前のスクリーンショット
