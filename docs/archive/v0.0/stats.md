# skillのstats
## 共通パラメーター
以下を共通して保持する。

- SkillCD:次に使用できるまでの基本CD
- TurnCD:次にTurnを迎えるまでの基本CD
- 対象:スキルの対象

対象:自身/先頭の敵/最後尾の敵/敵全体/先頭の味方/最後尾の味方/味方の前衛/味方の後衛/味方全体/etc

前衛/後衛は自身を起点として考える。（自身がindex:1なら前衛は無しで、後衛はindex:2とindex:3）

その他のパラメーターはスキルによる。

## メイン効果に付属することがあるパラメーター
### 貫通:n,m...
攻撃時、対象の次のパチモンにn%、更に次のパチモンにm%...のダメージを与える。
次のパチモンがいない場合、反対方向のパチモンにそのダメージを与える。（例として、対象が2体の場合は交互にダメージを与え、対象が1体の場合はその1体に複数回のダメージを与える。）



# pachimonのstats

## hp/maxhp/mn/maxmn/mnreg
スキルによってはマナを使用する。
マナは戦闘開始時に全回復する。
hpは持ち越し

## elementpower
（仮）
- fire
- water
- leaf
- electric
- poison
- earth
- ice
- dragon

攻防一体のステータス。

damege付与率 : スキル次第。

damage軽減率 = attribute / (attribute + 100)

## speed
TurnCDを短縮する。
100で2倍の速度、200で3倍の速度。
また、battle開始時のTurn順にも影響。

## skillheist
SkillCDを短縮する。
speedと同じ計算式。

## 貫通ボーナス
貫通ダメージにボーナス
100で2倍のダメージ、200で3倍のダメージ。



## ダメージ倍率/ダメージ軽減倍率
特に行やジム/四天王等での敵の強さ調整用。
全てのダメージを割合で上昇させたり軽減したりする。
