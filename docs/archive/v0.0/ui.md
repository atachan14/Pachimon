## Game

### Gameでの基本レイアウト
共通 : 上部に1行分のheadbar
PC/横長 : 3ペイン（左ペイン/Mainペイン/右ペイン）
スマホ/縦長 : 1ペイン(左右のペインを折りたたみ式（幅:0）にして、適時表示)

#### header
gold/現在行/保持バッジ数/他未定
表示内容は固定

#### 左ペイン/右ペイン
各画面に応じて表示。
スマホ版では、各画面での操作に応じて左右から開閉し、「閉じる」ボタンも設置。
基本的に左に味方情報、右に敵情報を表示。

#### Mainペイン
各画面に応じて表示。

### Map
Mainペインに被さるように上部からスライドイン/アウト
SlayTheSpire的なやつ。

Map上に表示される通常/ジム/四天王ノードの簡易情報
- Mod
- トレーナー
- バッチ

右ペイン:選択したノードの詳細と「進む」ボタンを表示。
左ペイン:保持パチモンの状態を表示。

### Mainペイン内の各状態
#### Start
ゲーム開始直後の、初期パチモン選択画面
Mainペイン:3*3のグリッドでパチモンを配置
右ペイン:選択されたパチモンを表示し、「決定」ボタンを表示。
左ペイン:決定されたパチモンを表示。

#### battle

##### グラフィックウィンドウ
[余白]  [敵1][敵2][敵3]

[味方3][味方2][味方1]   [余白]

以上が基本。
敵/味方の頭上にHPバーを表示。
味方を選択で左ペインに対象パチモンの情報を表示。
敵を選択で右ペインに表示。

##### コマンドウィンドウ
###### turn start
[たたかう][アイテム]

###### たたかう
スキルを3*3で表示。
スキル選択でグラフィックウィンドウにスキル詳細を表示。
スキル詳細内に「発動」ボタン。

###### アイテム
未定

### リワード獲得ウィンドウ
Mainペイン（battle）に被さるように上からスクロールイン（SlayTheSpire）。

獲得能力と[獲得する]ボタンを表示
- スキル
- mod（ステータス）
- パッシブ
- [獲得する]

獲得するボタンをクリックで左ペインに保持パチモン一覧を表示し、各パチモンの下に[この子がパチる]を表示。

[この子がパチる]を選択で、内部処理を行った後Mapウィンドウをスクロルインさせる。
