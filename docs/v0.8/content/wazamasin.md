# 技マシン専用Skill

## 既存Skillを技マシン専用へ移行する場合

- Skill ID `1～151`はPachimonの固定Skill兼Map振り分け対象として維持する
- 技マシン専用へ移す既存Skillには、Skill ID `1000～1999`を新しく割り当てる
- 空いた既存IDには代替となる通常Skillを配置する
- 技マシン専用Skillは`IsMapAssignable = false`とする
- 技マシンItem IDは、移行後のSkill IDから改めて生成する
- 移行前のSkillを固定SkillとしていたPachimonは、同じ既存IDへ配置した代替Skillを固定Skillとして使う
- 技マシン専用Skillも通常Skillと同じ最大6スロットへ入る。同じSkillの再取得は、Slotを増やさず既存Skillのアップグレードになる

## 共通仕様

- 本ファイル内の`戦闘の敵`は、原則として`先頭の敵`を表す
