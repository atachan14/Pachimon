# Status Contents

具体的な状態異常の仕様を系統別にまとめる。

共通の保持構造、Category、端数処理、時間進行は
[Status Effect Mechanics](../mechanics/status-effects.md)を参照する。

属性別ファイルには、SkillやPassiveが「どの状態異常を、どのValueで、誰へ付与するか」を記載する。
状態異常そのものの効果、再付与、終了条件、解除条件はこのフォルダを正本とする。
